# Discord-Controlled Minecraft Server Bot

A lightweight and cost-effective solution for Minecraft players to remotely control a locally hosted multiplayer server using Discord commands.

## Project Overview

Many Minecraft players, especially students, face a major obstacle when trying to play multiplayer: hosting a server. While it's possible to host locally, leaving a server running 24/7 consumes memory and electricity — something not everyone can afford. Renting cloud servers can be expensive and often laggy.

This project solves the problem by introducing a **Discord Bot** that can **start or stop a Minecraft server** on your local machine based on messages sent in a Discord channel. With this bot, as long as one person has their computer on, everyone can play together without paying for a permanent server.

## Features

- Start or stop the Minecraft server remotely via Discord
- Runs locally on any Windows/macOS/Linux machine
- No need for 24/7 cloud hosting
- Simple permission system to restrict usage
- Easily customizable
